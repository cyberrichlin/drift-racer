# 极速漂移 · 平面赛车

一个纯前端的竖屏平面赛车小游戏。**单文件、零依赖、无需构建**，双击即玩，也可直接部署到 GitHub Pages 在线试玩。

- 技术形态：单个 `index.html`（HTML + CSS + Canvas + 原生 JS 全部内联）
- 外部依赖：**无**（不含任何 CDN、图片、字体等外链资源，可完全离线运行）
- 适配：手机竖屏优先，宽屏下自动居中显示手机比例画布

---

## 一、目录结构

| 文件 | 说明 | 是否必需 |
| --- | --- | --- |
| `index.html` | 游戏本体（单文件，全部逻辑内联），**在线部署的核心文件** | 必需 |
| `start-server.cmd` | 本地一键起服务（Windows），自动开浏览器并给出局域网手机访问地址 | 本地运行用 |
| `README.md` | 本说明文档 | 建议保留 |
| `.nojekyll` | 空文件，让 GitHub Pages 跳过 Jekyll 处理，避免静态资源被拦截 | 部署建议保留 |

---

## 二、本地运行（三种方式，任选其一）

**方式 1：一键脚本（推荐）**
双击 `start-server.cmd`。脚本会自动打开浏览器并提示两个地址：

```
PC    : http://localhost:8080/index.html
Phone : http://<你的局域网IP>:8080/index.html   （手机需与电脑同一 WiFi）
```

关闭黑窗口即可停止服务。

**方式 2：直接双击 `index.html`**
无需任何服务，用浏览器打开即可玩（`file://` 方式）。本游戏无任何外部请求，因此这种方式同样完整可用。

**方式 3：手动起静态服务**
在游戏目录下执行：

```bat
python -m http.server 8080
```

然后访问 `http://localhost:8080/index.html`。

> 说明：仅本机游玩时，方式 1 与方式 2 效果一致；需要用手机扫码/输网址试玩时才必须用方式 1 或 3。

## 三、部署到 GitHub Pages（在线访问）

### 步骤

1. 在 GitHub 新建一个仓库（Repository），例如 `drift-racer`。免费在线 Pages 需要仓库为 **Public**。
2. 把 `index.html`、`.nojekyll`（可选 `README.md`）上传到仓库**根目录**。
   - 网页上传：仓库页 → `Add file` → `Upload files` → 拖入文件 → `Commit changes`
   - 命令行上传：
     ```bash
     git init
     git add index.html .nojekyll README.md
     git commit -m "feat: 极速漂移平面赛车"
     git branch -M main
     git remote add origin https://github.com/<你的用户名>/<仓库名>.git
     git push -u origin main
     ```
3. 打开仓库 `Settings` → 左侧 `Pages`。
4. `Build and deployment` → `Source` 选择 **Deploy from a branch**；`Branch` 选择 **main**、目录选择 **/(root)**，点击 `Save`。
5. 等待约 1 分钟，访问：

   ```
   https://<你的用户名>.github.io/<仓库名>/
   ```

   页面根路径会自动加载 `index.html`，无需在网址后加文件名。

### 部署注意

- 必须保证 `index.html` 位于仓库**根目录**（或改用 `/docs` 目录并把 Pages 目录设为 `/docs`），否则访问会 404。
- 纯静态站点**无需** Actions 工作流，也无需任何构建命令。
- 请保留 `.nojekyll`：GitHub Pages 默认用 Jekyll 处理站点，可能忽略以下划线开头的资源；本项目虽为单文件，保留该文件可避免后续新增资源时踩坑。
- 部署后如仍是旧版本，多为浏览器缓存，强制刷新（Ctrl+F5）即可。
- **无需为手机端单独准备任何文件**：GitHub Pages 部署完成后，手机与电脑访问的是**同一个网址**，页面本身已做竖屏、触摸与安全区适配，手机浏览器直接打开即可游玩。
- 页面已内联 favicon（data-URI 图标），不依赖任何外部图片文件，部署后不会出现图标 404。

## 四、操作说明

| 平台 | 操作 |
| --- | --- |
| 手机 / 触屏 | 左下**虚拟摇杆**：朝想去的方向拖动，车就往屏幕那个方向开；右下红色按钮：**按住 = 手刹漂移**，配合摇杆即可甩尾 |
| 电脑键盘 | `W` `A` `S` `D` 或 `↑` `↓` `←` `→` 同为屏幕方向控制，`空格` 手刹漂移 |

> 摇杆采用**镜头（屏幕）绝对方向**控制：手指往屏幕上方推 = 车往上开，往右推 = 车往右开，与车头当前朝向无关。即使车头朝向完全相反，车也会先自动转向目标方向再全速前进，不会出现「摇杆推下却倒车」的情况。单指即可控制二维方向，松手收油滑行。

## 五、玩法内容

- **5 条赛道**，难度递增：晨曦环道 → 沙丘折返 → 棕榈回旋 → 环礁狂飙 → 极限峡谷（后两条含高架立交桥）。
- **比赛设置**：赛道边界（沙地减速 / 墙壁撞击）、比赛圈数（2 / 3 / 5 圈）。
- **5 辆车并排起跑**（含电脑对手），具备漂移甩尾、沙地限速、撞墙反弹、追尾互动等机制。
- 完赛后展示最终排名与单圈成绩。

## 七、双端访问与部署清单

### 7.1 电脑端

| 场景 | 地址 | 说明 |
| --- | --- | --- |
| 本地 | 双击 `index.html`，或 `http://localhost:8080/index.html` | 无需服务亦可直接玩 |
| 线上 | `https://<你的用户名>.github.io/<仓库名>/` | 宽屏自动居中手机比例画布；键盘 `WASD` + `空格` 漂移 |

### 7.2 手机端

| 场景 | 地址 | 说明 |
| --- | --- | --- |
| 局域网试玩 | `http://<电脑局域网IP>:8080/index.html`（`start-server.cmd` 会自动给出） | 手机需与电脑同一 WiFi |
| 线上试玩 | `https://<你的用户名>.github.io/<仓库名>/` | 与电脑端同一网址，无需额外配置 |

手机端已具备的适配：

- 竖屏全屏（`position:fixed` 视口，规避移动端地址栏高度抖动）；
- 刘海 / 圆角安全区（`env(safe-area-inset-*)`）；
- 禁用双指缩放、长按选择与页面滚动回弹（`touch-action:none`、`overscroll-behavior:none`）；
- `pointer` 事件 + 指针捕获：**虚拟摇杆与漂移键可多指同时操作**（左拇指推杆、右拇指漂移互不干扰），手指滑出控件也会正确松手；
- 首次点「开始比赛」自动解锁音频（浏览器自动播放策略要求）。

### 7.3 部署上传清单

| 文件 | 是否上传 | 说明 |
| --- | --- | --- |
| `index.html` | **必须** | 游戏本体，须位于仓库根目录 |
| `.nojekyll` | 建议 | 跳过 Jekyll 处理，避免下划线开头的资源被忽略 |
| `README.md` | 可选 | 仓库说明文档，不影响运行 |
| `start-server.cmd` | 不需要 | 仅用于本机起本地服务 |

> 一句话结论：**只上传 `index.html`（外加 `.nojekyll`）即可**，电脑端与手机端都能通过线上网址正常打开并游玩。
